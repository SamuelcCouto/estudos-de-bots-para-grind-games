# DDTank Bot - instrucoes para o Claude Code (leia primeiro)
Projeto: bot automatico de DDTank (servidor Betel). **Leia `ddtank/DOCUMENTACAO.md`** (arquitetura, decisoes, backlog, combinados) e,
para o historico tecnico, `ddtank/NOTAS.md`. O usuario fala portugues e quer explicacoes simples.
- Trabalhe e faca push **so** na branch `claude/wonderful-rubin-3oyqi3`; sem PR a menos que peca.
- Antes de commitar rode todos os `python testes/test_*.py` (na pasta `ddtank`).
- Os zips em `ddtank/envio/` sao gravacoes do usuario para analise: analise, depois `git rm`.
- Nao invente coordenadas/telas: peca gravacao (painel > "Gravar a MINHA jogada").
